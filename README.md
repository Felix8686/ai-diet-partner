# AI Diet Partner

一个面向 25–40 岁上班族的 AI 饮食管理 MVP。

核心不是记录每一口，也不是把用户训练成“健身餐执行机器”，而是在预算、时间、外食、厨具和个人食材环境约束下，持续给出更容易长期执行的饮食方案。

## 当前阶段

MVP foundation：PWA 前端骨架、3 步建档、本周方案、采购清单、每日极简反馈与初始数据模型。

## 产品边界

- 只解决饮食相关问题：这一顿怎么吃、这周怎么买、为什么调整。
- 不做步数、喝水、久坐等泛健康提醒。
- 前五个大版本不加入吉祥物或品牌 IP。
- 不做卡路里逐项记录、冰箱库存管理、全国食材库或餐厅营养数据库。
- 外食是正常场景，不视为偏离。

详细约束见 `AGENTS.md` 与 `docs/PRODUCT.md`。
